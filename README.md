# Топ-10

Приложение для создания рейтингов из видео, текстов и изображений с экспортом в PNG и ZIP.

**[Посмотреть онлайн](https://milyygg.github.io/top-10/)**

## Запуск

Node.js 24: `npm ci`, затем `npm run dev`. Сборка: `npm run build`.

Черновик хранится в памяти вкладки и теряется при перезагрузке. Локальные фотографии обрабатываются на устройстве. Для видео используются внешние сервисы YouTube.
